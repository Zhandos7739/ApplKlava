# ApplKlava

Системная клавиатура Android (IME) с динамической зоной нажатия.

## Фичи
- компактная высота под телефон (~32% экрана)
- **свайп по пробелу** — RU ↔ EN (как на Honor)
- кнопка **Обыч.** — назад на системную клаву
- подсказки со **сленгом** (норм, щас, хз, го, кринж, vibe…)
- без больших кругов зоны

## Установка
1. `dist/ApplKlava-debug.apk`
2. Включить ApplKlava в настройках клавиатур
3. Выбрать её

```bash
npm run build:apk
```
