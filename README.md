# ApplKlava

Системная клавиатура Android с **динамической зоной нажатия** (режим Нано).

## Важно

Это не отдельное приложение-игрушка, а **IME** — замена стандартной клавиатуры телефона. Печатает в WhatsApp, браузере, SMS и т.д.

На клавиатуре кнопка **«Обычная»** возвращает системную клавиатуру (Gboard / Samsung / …).

## Установка

1. Установи `dist/ApplKlava-debug.apk`
2. Открой приложение ApplKlava
3. Нажми **«Включить ApplKlava»** → включи переключатель
4. Нажми **«Выбрать ApplKlava»** → выбери её
5. Тапни в поле проверки и печатай

## Сборка APK

```bash
npm run build:apk
```

Готовый файл: `dist/ApplKlava-debug.apk`

## Как работает Нано

- зона клавиши не жёсткий прямоугольник, а вес: частотность / расстояние²
- быстрая печать → зона шире (прощаем промахи)
- самокалибровка смещения пальца
- кнопка «Обычная» = назад на системную клаву
