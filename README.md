# ApplKlava

Виртуальная клавиатура с **динамической зоной нажатия** (режим «Нано») для телефона.

## Идея

Вместо жёсткого «попал в прямоугольник клавиши» система сама угадывает букву:

- взвешенные зоны (частотность / расстояние²)
- шире зона при быстрой печати
- самокалибровка смещения пальца
- быстрое переключение **Нано ↔ Обычный**
- слайдеры ширины зоны, частотности, прощения скорости, калибровки

Backspace сразу после буквы = промах (счётчики для сравнения режимов).

## Запуск в браузере

```bash
npx --yes serve www -p 4173
```

Открой на телефоне в той же сети или через USB port-forward.

## Android APK

```bash
npm run build:apk
```

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`  
Также копируется в `dist/ApplKlava-debug.apk`.

## Режимы

| Режим | Поведение |
|-------|-----------|
| **Нано** | умный выбор клавиши + калибровка |
| **Обычный** | классический hit-box |
