ApplKlava

Это больше не веб-демо. Нужен APK — системная клавиатура (IME) с кнопкой Обыч. для возврата к стандартной.

  1. Установи dist/ApplKlava-debug.apk
  2. Открой приложение → «Включить ApplKlava»
  3. «Выбрать ApplKlava»
  4. Печатай в любом поле. Кнопка Обыч. слева внизу вернёт системную клаву
